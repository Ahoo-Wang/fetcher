# RecordView implementation plan

Approved scope: `2026-09-05-wow-view-engine-design.md` and its UI spec. Continue the existing independent package; no commit or publishing in this task.

## Shared contracts and boundaries

- `recordModel.ts` owns definition, record instances, fixed-scope host, session and engine snapshot types. `recordReactTypes.ts` owns renderer/table contracts. The React layer consumes the headless engine; every query is server-side.
- `recordValidation.ts` exports `validateViewDefinition`, `validateViewInstance`, `readRecordValue`, `getRecordKey`, `validateRecordRows`. Validators throw `Error`; inputs are checked at host/config boundaries. `sameFilterState` supplies structural equality.
- `ViewEngine` owns load, select, filter drafts, queries, selection, saving and lifecycle. UI receives stable snapshots via `getSnapshot` and `subscribe`. Public methods: `load`, `selectInstance`, `reloadInstance`, `applyFilter`, `setFilterDraft`, `setFilterPending`, `setFilterMode`, `setSort`, `setColumns`, `setPage`, `setPageSize`, `nextPage`, `setTitle`, `setSelection`, `refresh`, `restore`, `save`, `saveAs`, `dispose`, `getPermissions`. All optional instance IDs default to selected; async mutations return Promise<void>, saveAs returns Promise<void>.
- RecordTable is engine-independent. TanStack Table 9.2.4 supplies table state; shadcn base-nova supplies presentation. Column resizing commits at drag end, with numeric settings and keyboard alternatives. No client filtering/sorting/pagination.
- ViewPage composes RecordView with grouped instance navigation, dirty/save/save-as/restore/reload controls. Sidebar collapse is local UI state; narrow layouts do not change persisted preference.
- Keep existing filter contracts: field `editor`, definition `filterEditors`, `ViewExtensions.filters`. No aliases. Filters apply only on 查询. Their pending draft blocks view saves.
- Writes validate host echoes and preserve edits made while awaiting. Unknown outcome forces explicit instance reload. Local read-only inputs are valid. Renderers are host-local React components; remote references remain JSON.
- Pagination, results, selection, drafts, navigation and loading errors are not persisted. Column order/width/visibility affect presentation only; summary functions configure a separate aggregate query. Source projection stays default.

## Tasks

1. Root: shared contracts, boundary validation, QueryApi abort declarations, dependency integration.
2. Independent core task: `ViewEngine.ts` and race/query/save tests.
3. Independent table task: RecordTable, column settings and their focused tests, Table/Checkbox primitives only.
4. Root: RecordView, ViewPage, lifecycle tests, Storybook scenes and API documentation.
5. Integrate, review correctness and real UI, run affected tests/builds and Storybook interactions. Report concrete remaining limitations.
