# 轻量 BI 交互优化验收

## 本次变更

1. 维度拥有 `label: { field, alias, title }` 显示字段。编译器生成 ANY，并以结果列 `labelFor` 关联维度。用户只编辑一个维度，名称不再计入用户统计指标。
2. 移除旧 `AnalysisPresentation.labels` 配置及其独立下拉框；清除维度显示字段时同步清理排序、表格引用。服务端指标限额包含生成的 ANY；仍校验字段授权、别名冲突。
3. 有效分析默认结果优先，配置收起；未完成/无效配置默认展开。ViewPage 与独立 AnalysisView 保持一致。执行口径改为可展开摘要。
4. 一、二维图表默认映射分类轴与系列，仍拒绝丢失第三个维度或前端重新聚合。
5. 内置图表类型、名称、设置能力由 `ANALYSIS_VISUALIZATIONS` 统一维护，设置与投影校验共用。仍使用现有 Recharts 渲染器；未增加任意第三方图表插件加载机制。

## 验证

- 浏览器实际查看结果首屏、维度编辑：商品 ID 与商品名称在同一编辑器中，统计指标只显示销售额。
- 同名不同商品保持独立，坐标轴与提示框沿用名称回退规则。
- 390px 窄屏 DOM 实测：主体宽 375px、视图宽 351px，无页面横向溢出；配置对话框可打开并返回结果。截图服务在视口模拟下产生异常长图，未将该截图作为视觉验收证据。
- 21 项受影响浏览器回归通过，包含性能场景、数据/分析切换、商品维度保存后重载。此前全量中的 5 项失败均为默认面板状态变更后的旧测试操作，已修正并纳入该次回归。
- 静态 Storybook 构建通过：19 个导航目标、170 个隐藏回归校验通过。
- 类型、ESLint、中英文文档按变更同步验证。

未进行真实业务用户可用性研究，不能据此宣称业务用户学习成本已经达标。旧维度标签验收记录中的展示层绑定方案已被本方案取代。
