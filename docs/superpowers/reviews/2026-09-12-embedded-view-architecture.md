# EmbeddedView 架构审查与修订

审查基线：7f8083d9；范围为 view-engine 的仪表盘运行时、独立运行位置、共享结果组件及嵌入入口。

## 结论

存在局部职责混合与状态边界耦合，现有查询/渲染基础可以继续复用。本次按实际问题重构，独立复审最终 PASS。

| 已确认问题                                                                    | 修订后的职责                                                                                                          |
| ----------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| DashboardRuntime 按保存实例单例，导航切换控制其暂停；同实例多个嵌入会共享状态 | openPosition 支持三类型，嵌入按独立 positionId 管理运行状态、预算及释放；管理导航维持自己的运行对象                   |
| 是否将仪表盘筛选写回草稿由保存权限决定                                        | 嵌入位置明确为浏览用途；管理员也只修改当前浏览状态，位置 dirty=false 且管理/保存命令拒绝位置                          |
| DashboardPanelContent 同时分派记录/分析内容、处理查询错误和引用错误           | DataViewContent 统一记录/分析结果、查询状态和重试；DashboardPanelContent 保留卡片头、引用/绑定错误及数据详情          |
| 记录/分析筛选壳依赖工作台选择，容易与首页共享草稿                             | EmbeddedView 读取保存 baseline，拥有位置挂载周期；EmbeddedDataView 的筛选缓冲在查询前留在本地，刷新继续使用已应用条件 |
| 并发/队列受理拒绝只抛错，不保证有可见查询错误                                 | 共享记录/分析查询边界发布未受理错误，保留活跃请求及旧执行快照；嵌入默认排队且失败可重试                               |

## 组件与所有权

- `EmbeddedView` 是公开入口，支持 dashboard、record、analysis。宿主提供 engine binding、保存 instanceId、可选打开完整视图回调。
- 宿主持有 engine；组件持有它创建的位置，目标或访问范围变化、卸载时释放位置，不修改宿主选中视图。
- `DataViewContent` 是包内共享数据结果呈现层，继续复用 RecordContent 与 AnalysisResult；独立工作台保留现有结果组件。
- 仪表盘子面板继续限制为记录/分析引用；顶层仪表盘本身可嵌入首页。
- `DataViewPosition` 统一数据位置类型，移除与它重复的 DashboardPosition 别名。
- 首页只展示嵌入内容时，初始化实例列表的 defaultInstanceId 使用 null，避免额外启动工作台默认视图。

## 对抗验证

覆盖同保存实例双嵌入、工作台导航独立、管理员筛选不污染保存会话、独立分页/卸载、StrictMode 重挂载、目标切换后旧请求迟到、位置创建失败回收、全局预算不被多个嵌入绕过、并发仅1时双分析排队、初次分析失败刷新恢复、BUSY/队列满及已有请求所有权保持。

独立审查曾拒绝“忽略启动异常”的实现：查询在受理前拒绝会造成 idle 空白。修订后共享查询状态可观察，只有已发布的错误交由结果组件呈现，未发布的初始化失败有重试入口。

## 展示命名与可访问性

用户确认示例命名为“业务仪表盘”，入口 `view-engine-embedded-view--dashboard`。重复嵌入采用宿主提供的不同展示title；标题只影响展示和区域/分页/筛选器名称，不进入保存实例、查询或位置生命周期。六个嵌入故事通过包括landmark唯一性的浏览器检查，独立复审确认这组label传递不影响运行逻辑。
