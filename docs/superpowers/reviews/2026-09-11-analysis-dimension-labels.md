# 分析维度名称映射验收

展示配置增加 `labels: [{ dimension: 'productId', metric: 'productName' }]`。维度别名绑定 ANY 输出，查询和分组身份不变。

- 公共投影层按维度身份解析名称，坐标轴、饼图标签和系列图例共用；Tooltip 同时展示名称与 ID。
- 同名不同 ID 追加 ID；空名称和同一 ID 跨系列名称冲突回退为 ID。不会将 ANY 当作数值指标或重新聚合。
- 显示编辑器提供分组名称、系列名称选择；只列出 ANY 输出。删除维度或指标时清理失效引用。
- 商品 Storybook 场景验证两种名称显示、切换不查询、保存与新引擎重载后恢复配置。
- 浏览器实际检查：轴显示“机械键盘 · P-1001”“无线鼠标”“机械键盘 · P-1003”；提示框显示“无线鼠标 · P-1002”和销售额。

定向投影测试 13 项、图表浏览器测试 16 项、ESLint、构建和文档检查通过。示例使用离线聚合结果；本变更不改变后端请求。
