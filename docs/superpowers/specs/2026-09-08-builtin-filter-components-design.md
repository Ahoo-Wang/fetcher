# View Engine 常用内置筛选器设计

## 目标与确认状态

补齐常见业务筛选输入，让使用者通过组件配置直接接入，减少重复实现多选、远程搜索、分页与恢复逻辑。继续使用现有组件属性持久化和组件注册编译契约。

用户已确认首批组件范围、远程分页和职责边界。本文已获用户确认；随后补充“尽可能复用 Fetcher 生态已有能力”约束，实施计划据此制定。筛选器阶段已完成，验证结果见对应实施计划；单元格阶段尚未实现。

总体需求分两阶段交付：本设计只覆盖筛选器；标签/状态、链接、金额/百分比和可复制文本等单元格组件是下一阶段，不因本次拆分而取消。

## 范围

首批包括本地多选、远程单选/多选、多值文本、日期时间区间；复用并增强已有单选、本地搜索和日期时间控件，不重建一套基础 UI。

树选择、级联选择、图片/头像选择、用户创建新候选、富文本以及表格编辑不在本阶段。客户、员工、商品等领域选择器通过远程数据源配置组合，不分别定义业务组件。

继续使用包内 shadcn/Base UI 控件和现有依赖；允许按需增加 Fetcher 生态的内部 workspace 依赖，不引入新的外部库。保持主题、弹层容器、紧凑布局及 React Compiler 规则；不增加 HTTP 客户端、缓存框架或另一套过滤表达式。

## 接入与职责

- 字段继续通过 `editor.name + options` 引用组件。内置注册项复用 `FilterRegistration`，每项共同提供渲染、纯编译及清空能力。
- 内置组件名采用明确命名空间，避免与业务注册名碰撞；业务扩展继续显式注册，不因缺少业务注册而偷偷降级为另一组件。
- 远程数据源按名称放在运行时扩展注册中，通过类型化接口交给内置选择器。JSON 只引用数据源名称，不保存函数、鉴权信息、URL 或实例对象。
- 远程候选服务不加入 `ViewHost.definition/instance/preference/permission`，也不复用业务记录的 `resolveSource`；其职责是辅助编辑器选择值。
- 核心编译器不发请求、不依赖 React 或候选缓存。无头引擎能够编译已保存的内置组件属性。
- 单独使用 FilterPanel 与经 ViewPage 使用时，采用相同注册与候选服务契约。

## 值、配置与恢复

选择值支持字符串和有限数字 ID，保留类型；数字 `1` 与字符串 `"1"` 不等价。标签使用普通文本，不能参与查询编译。

保存的属性包含选择值和对应的显示标签快照。多选按首次选择顺序保存并去重。配置中的候选来源、搜索提示、分组等展示选项与实际选中属性分开。

未选择或空集合表示未设置，编译时不产生该条件；不能把空集合编译为恒假查询。清空只重置该组件的值，保留筛选器节点、绑定和配置。控件编辑遵循既有手动查询流程，不因候选搜索或分页触发记录查询。

恢复时先显示保存的标签，无标签时显示原 ID。远程标签回填进入运行时展示状态，不调用属性修改回调，不把视图标为已编辑，也不生成待查询变化。用户重新选择时才写入新的值与标签快照。

候选当前页没有某个已选 ID，不代表该 ID 失效。只有按 ID 回填服务明确返回缺失，才标记“已不可用”；仍保留原 ID 和标签，允许用户主动移除。回填失败显示可重试状态，不能伪装成失效或删除选择。

## 本地单选与多选

- 共享候选结构：ID、标签、可选分组、禁用状态；组内顺序由提供方决定。
- 多选展示复选状态，选中后保持弹层打开，支持连续选择和移除已选项。
- 本地搜索按标签过滤候选，不改变选中集合。分组标题不参与选择。
- 多项选中时紧凑展示摘要及数量，可查看完整集合；单个超长标签不撑开面板。
- 不提供含义不明确的跨页“全选”。首批也不增加批量选择全部候选入口。
- 已选但禁用的候选保持显示且允许移除；整个控件 disabled 时不能选择、清空或移除。

## 远程候选服务

候选查询接收搜索词、可选分页游标和必需的 AbortSignal，返回候选列表及可选下一页游标。游标是业务服务提供的不透明字符串，不由组件推算页码或总数。

按 ID 回填接收选中 ID 集合和 AbortSignal，返回匹配项及明确缺失的 ID。请求失败与“ID 不存在”是不同结果；回填响应顺序不改变选择顺序。组件不据缺省返回项自行猜测删除状态。

分页交互首批采用可访问的“加载更多”按钮，不要求滚动触底才能操作：

1. 首次打开弹层后读取第一页，未打开时不预取整个候选列表。
2. 搜索输入默认防抖 300ms，允许配置为 0；中文输入法组合期间不发搜索请求。
3. 搜索词变化时取消旧候选请求、重置分页；已选值和标签保持。
4. 同一搜索会话最多一个候选查询在途。以请求序号或等价令牌丢弃过期结果，不能只依赖服务端遵守 AbortSignal。
5. 下一页按 ID 去重追加；重复 ID 的显示信息允许刷新，不重复生成选项。
6. 首次加载、搜索无结果、首屏失败、下一页失败分别呈现。下一页失败在列表底部重试，保留已加载列表。
7. 服务没有下一页游标时隐藏加载更多；重复返回已消费游标视为分页错误，停止继续请求，避免循环加载。
8. 关闭弹层取消候选请求；重新打开保留当前已完成结果，若关闭时请求未完成则重新请求该页。
9. 组件卸载、数据源变化或访问范围变化时，取消查询与回填并清空相应缓存。遵循现有视图作用域生命周期，不创建跨用户的全局候选缓存。

标签回填与候选搜索是独立请求，不能互相取消。迟到的回填响应不得重新加入已被移除的选择。

## 多值文本

适用于批量订单号、邮箱、标签等字符串集合。支持逐项输入及粘贴，以换行、中英文逗号和分号拆分，去除两端空白、忽略空项、按完整字符串去重。

不自动按空格拆分、不改写大小写、不推断数字类型，以免破坏带空格的名称或带前导零的编号。首批不承担 CSV 引号和转义解析。

输入法组合期间不提交；有尚未提交的输入时 Enter 先提交当前项，不同时触发记录查询。用户继续按 Enter 才走面板现有查询行为。删除与粘贴只改变草稿。

## 日期时间区间

使用现有日期和时间组件及字段 timeZone，保存两端组件属性，日期时间端点保留已有 offsetMinutes 语义。

- 两端都未设置：整体未设置，不编译条件。
- 只填一端或端点输入不完整：保留原始输入并报告无效，阻止查询与保存。
- 开始晚于结束：就地显示错误；不交换输入或自动截断。
- 完整且有效：沿用现有 BETWEEN 查询语义，不新增区间操作符。
- 日期字段保持 YYYY-MM-DD；日期时间字段编译为毫秒时间戳。不能将只填日期默认为“当天结束”，不能自动追加 23:59:59.999。
- DST 不存在时刻仍拒绝；重复时刻遵循已修复的有效偏移优先、否则选择较早一次规则。

“最近七天”等动态相对区间和单边开放区间不加入本组件首批契约；现有相对时间操作仍可使用。

## 交互与错误呈现

键盘能够打开、搜索、浏览候选、选择/取消、加载更多、重试和关闭。多选状态不只靠颜色表达，候选与已选摘要提供可访问名称。

选择器内部的 Enter 用于确认候选，不能冒泡误触发面板查询；输入法组合期间也不能查询。关闭后焦点回到触发器。搜索、分页错误贴近候选列表，字段值校验错误继续由现有 FilterPanel 呈现。

加载使用现有 Spin 及屏幕阅读器状态说明，不重复铺满“加载中”。未知组件名或数据源名显示明确配置错误，不把它当成空候选结果。字段数据和远程响应需要运行时验证，非有限数字 ID、错误游标类型等不进入持久化属性。

## 验证与交付

1. 本地单选/多选：数字与字符串 ID 区分、分组、禁用、搜索、连续选择、清空及已选摘要。
2. 远程：防抖、输入法、取消、过期响应、分页去重、下一页失败重试、重复游标保护。
3. 恢复：JSON 保存后以新 host/engine 重开；搜索结果不包含已选项时仍回显；标签回填不修改查询、选择和 dirty 状态。
4. 失效：回填明确缺失、服务失败、迟到响应、数据源和访问范围切换分别验证。
5. 编译：空值不生成条件；多值对应已有集合操作；日期时间区间不完整、逆序与 DST 端点按约定处理。
6. 交互：键盘、读屏状态、暗色、窄容器、弹层主题，以及 Enter 与手动查询互不冲突。
7. 内置组件均通过公开包入口进入 Storybook；展示故事与复杂回归故事分离。
8. 在 LocalStorageViewHost 恢复示例中验证组件属性保存、重新挂载与纯编译，候选服务仍由前端运行时注入。
9. 运行受影响包的双模式测试、类型检查、React/Compiler lint、构建、打包和 Storybook 测试；更新双语 README 与公开 API 参考。

## 自检

本设计只补齐筛选器，不引入通用异步数据框架。查询编译、组件属性、候选展示缓存和视图持久化职责分开；恢复、取消、错误及权限作用域都有可验证行为。后续单元格组件另行设计，不与远程候选生命周期耦合。

## Fetcher 生态复用约束

- 优先复用 `@ahoo-wang/fetcher-react` 的 `useExecutePromise`、`useDebouncedCallback` 或其组合，承担异步状态、防抖、取消与过期请求保护；不在 view-engine 中复制一套通用异步 Hook。
- 分页结果复用 `@ahoo-wang/fetcher-wow` 的 `CursorPage<T>`（`list`、`nextCursor`）；查询端复用其 cursor/size 字段约定，关键词到业务 Filter 的转换留给候选服务。
- 接入示例使用 Fetcher/现有 Wow 查询客户端传递 AbortSignal，鉴权和错误处理复用宿主既有配置，不新增请求包装框架。
- `viewer/RemoteSelect` 依赖 Ant Design；复用其依赖的底层 Hook 和已验证行为，不将 Ant Design 组件或样式引入 view-engine。
- 对主动取消、忽略取消的迟到结果、异步取消回调等行为先验证共享 Hook。若缺口被复现，在 `packages/react` 修复共享原因，保持公开 Hook 签名不变。
- 内部依赖需要通过打包验证：view-engine 核心入口不能因 React Hook 复用而加载 React、DOM 或网络服务，不能使用跨包 src 深层导入。

## 已落地的复用方式

view-engine 通过新的公开 ESM 子路径 `@ahoo-wang/fetcher-react/core` 复用通用 Hook，避免引入总入口的集成模块副作用。根入口保持兼容。单选与多选的公开 props 使用判别联合；命名内置组件在未显式配置 operators 时提供适用默认操作。示例及运行时/持久化边界验证已完成，记录在实施计划中。
