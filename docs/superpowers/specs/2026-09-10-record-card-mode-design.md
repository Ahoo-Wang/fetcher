# Record View 卡片模式设计

日期：2026-09-10。状态：对话设计已确认，书面规格待审阅；尚未实现。

## 目标与范围

在现有 record 视图中增加可保存的卡片展示模式。卡片独立配置标题、封面、摘要字段和操作区，复用 ViewEngine 的查询、筛选、排序、分页、选择、刷新与实例保存流程。表格仍为现有实例的默认展示。

采用独立卡片配置，而非将表格列逐项排成卡片：后者无法清晰表达标题与封面。也不增加任意布局编辑器或整卡插件系统；现有字段和操作渲染器覆盖本次扩展需求。

不增加依赖、不修改构建配置；不增加拖拽布局、独立卡片汇总配置、无限滚动或详情路由。

## 当前实现与接入位置

- 基于 origin/main 的 6451c222；当前 RecordView 固定渲染 RecordTable。
- RecordViewConfig.presentation 仅允许 table，表格列配置由校验器、工具栏和汇总逻辑消费。
- RecordEdits.setColumns 通过 SessionStore 更新实例并按指标变化同步汇总；展示切换应沿用实例更新机制，不经过记录查询流程。
- RecordCell 已承担字段取值、格式化、内置及自定义 cells、rowActions 渲染；卡片复用该能力及 RecordRendererBoundary，避免新增平行注册表。
- RecordView 已集中提供过滤、操作区、分页和刷新生命周期，卡片仅替换结果展示区域。

## 配置契约

保留 presentation.table 及现有 columns 原样，增加可选 card 配置，并将当前布局扩展为 table 或 card。layout 为 card 时必须存在有效 card；旧的 table 配置无需迁移。RecordTablePresentation 保持原有 table 语义，增加卡片展示类型及公共联合类型；共享 table 配置始终可访问。

卡片配置包括：

| 配置 | 规则 |
| --- | --- |
| title | 必选字段引用，允许使用现有字段渲染器及实例级覆盖；默认格式化值为空时回退记录主键 |
| cover | 可选图片地址字段引用；默认 16:9、object-fit: cover，图片替代文本来自标题的纯文本格式化值 |
| fields | 有序摘要字段列表，可为空；每项具有稳定 id、字段路径、可选显示名称及 renderer，默认显示字段名和值 |
| actions | 可选操作区配置，使用现有 RendererReference；未显式指定渲染器时使用 definition.recordActions.row；省略表示隐藏操作区 |

标题和摘要复用已有字段渲染语义，封面使用图片专用呈现。配置保存为 JSON；不持久化函数、React 节点或运行时渲染器。

所有字段必须存在于 ViewDefinition；封面字段必须为 string 类型。摘要 id 必须唯一，引用和选项沿用现有 JSON 校验。无效配置在加载或更新实例时拒绝，不等到查询发出后处理。已有记录主键可能未包含于字段定义时，默认标题直接读取 rowKey；配置须明确支持这一主键引用，不强制修改宿主定义。

保留现有公开方法和扩展名称（包括 setColumns、tableActions、renderTableToolbar），其在卡片下继续服务对应的共享操作。新增布局与卡片配置更新方法，通过现有实例校验与 dirty 机制生效。实现时用类型消费检查确认旧用法仍可编译；若发现不可避免的公共 API 破坏，先报告并按仓库版本规则处理。

## 切换与设置

默认工具栏新增“表格／卡片”选择及“卡片设置”入口；表格模式继续显示列设置，卡片模式显示卡片设置。已有自定义工具栏上下文增加对应布局和配置操作，defaultContent 包含默认控件。

第一次切到卡片时生成最小配置：主键作标题，无封面、无摘要，有默认行操作时启用操作区。设置界面允许选择标题、封面，添加、删除及上下移动摘要字段，选择摘要字段后使用字段默认渲染器；允许启用或关闭默认操作区。实例级 renderer 覆盖由配置 API 提供，首版 UI 不编辑任意 JSON 选项。

设置在本地表单草稿中编辑，应用时一次校验和更新，取消不改变实例。切换布局与应用配置标记视图已编辑，沿用保存、另存为、恢复和权限行为。返回表格再切回卡片时，双方配置均保留。

纯展示切换或卡片配置更新不得重新读取记录、改变筛选草稿、排序、页码、游标或当前选择；进行中的查询继续完成。排序仍使用 config.sort 和现有 setSort，切到卡片不增加独立排序状态或新排序面板。

## 渲染与交互

新增 RecordCards，并由 RecordView 根据 layout 选择结果组件；过滤面板、已应用条件、共享操作区和分页继续共用。卡片使用 CSS Grid 自适应列数，窄屏为单列，继承 fve 主题、字体与语义色。无需固定桌面列数配置。

每张卡片包含可选封面、标题、有序摘要字段及可选操作区。长文本换行，摘要可视觉截断但保留可访问完整内容。整卡默认不绑定点击跳转，以免与选择框、链接、按钮冲突。

selectable 开启时提供每卡选择框和本页全选；选中项继续由引擎按 rowKey 管理，批量操作接收同一 selectedRowKeys。使用语义列表和标题结构，控件具有可访问名称、键盘操作和可见焦点。

卡片模式复用现有加载、空结果、失败重试语义，后台刷新保留已有结果。字段或行操作渲染器缺失、抛错仅在对应区域提示，不使整页崩溃。未配置封面时省略图片区域；配置了封面但值缺失、地址不允许或加载失败时显示占位。图片地址仅接受 http/https 和站内相对路径，复用适用的现有 URL 校验；使用浏览器图片加载，不添加服务端抓取。

## 汇总与生命周期

表格汇总配置继续保存在 table.columns，切换时不删除。卡片首版不展示或编辑汇总，现有汇总生命周期与缓存继续沿用，切换本身不新增汇总请求。返回表格显示现有汇总状态。由筛选、分页或刷新引起的汇总更新继续遵循现有引擎行为。

两种布局共用 session、查询取消与刷新策略；不新建卡片 session、QueryApi 或独立数据缓存。

## 实现范围与验证

改动集中于 packages/view-engine 的 record 模型、实例校验、引擎编辑入口、RecordView/工具栏及新增卡片和设置组件；按需复用字段呈现内部函数，保留既有公开接口。更新核心和 React 导出、API 参考、README 及对应中英文 wiki，补充 Storybook 示例。

验收必须覆盖：

1. 旧 table 实例加载不变；卡片配置 JSON 保存、加载、另存为和恢复保持一致；非法字段、重复 id、非法 renderer 配置被拒绝。
2. 布局来回切换保留双方配置、筛选草稿、排序、分页和选择；查询调用计数不增加，进行中的查询不被布局切换取消。
3. 首次默认配置支持 rowKey 未列入 definition.fields 的既有定义；卡片标题为空时有主键回退。
4. 自定义 cells、rowActions 与批量选择正常；渲染失败隔离；封面缺失、非法地址和加载失败有稳定回退。
5. 浏览器实际验证切换、设置应用/取消、选择、分页和键盘焦点；检查窄屏、明暗主题、长文本与图片占位。
6. 运行受影响包及依赖构建、包测试与类型检查、相关 Storybook 浏览器测试、文件级格式和 lint；文档更新运行 wiki build。任何提交前 pnpm test:unit 必须通过。

## 规格自审

- 表格配置始终保留，兼容已有实例与汇总字段读取。
- 展示更新与记录查询分离，不承诺停止已有的汇总生命周期。
- 默认主键标题不假定 rowKey 必须出现在可选字段列表中。
- 区分可配置的 renderer API 与首版设置 UI，未承诺 JSON 渲染器编辑器。
