# Record View 卡片模式设计

日期：2026-09-10。状态：已实现并完成本地构建、单元测试和浏览器验证；未发布。

## 目标与范围

在现有 record 视图中增加可保存的卡片展示模式。卡片独立配置标题、封面、摘要字段和操作区，复用 ViewEngine 的查询、筛选、排序、分页、选择、刷新与实例保存流程。表格仍为现有实例的默认展示。

采用独立卡片配置，而非将表格列逐项排成卡片：后者无法清晰表达标题与封面。也不增加任意布局编辑器或整卡插件系统；现有字段和操作渲染器覆盖本次扩展需求。

不增加依赖、不修改构建配置；不增加拖拽布局、独立卡片汇总配置、无限滚动或详情路由。

### 架构约束

架构清晰优先于文件数和差异行数。允许为本次功能重构必要的模块或层级；出现职责混杂、反向依赖、循环依赖或多处重复维护同一规则时，应修正责任归属，不靠额外分支、跨层调用或复制代码维持表面兼容。重构需有当前代码和实际调用路径作为依据，不为假想布局增加框架。

- 模型、配置初始化、校验与纯策略不依赖 React、宿主服务或引擎实例。
- 引擎负责会话更新、查询与汇总生命周期，通过现有 Host 接口访问宿主能力；不承担界面草稿、布局 DOM 或组件注册实现。
- React 组件负责呈现、交互草稿与局部错误，通过引擎公开操作提交变更；不绕过引擎修改会话或直接调用查询服务。
- 表格与卡片确有共同职责时，将其放在双方依赖的中立模块；布局特有行为留在对应组件，不要求卡片逐步模拟整套表格结构。现有类型投影或薄适配在语义一致时可以继续使用。

重构只覆盖本次功能实际触及的责任边界，复用现有模型和机制，不增加无消费者的抽象。实施计划中的文件划分可依据源码证据调整；若调整改变已确认的产品行为、持久化契约或版本边界，先明确说明该变化。验收同时检查依赖方向、规则是否单一维护和既有行为回归，不能只以编译通过判断架构合理。

## 当前实现与接入位置

- 基于 origin/main 的 6451c222；当前 RecordView 固定渲染 RecordTable。
- RecordViewConfig.presentation 仅允许 table，表格列配置由校验器、工具栏和汇总逻辑消费。

- RecordView 已集中提供过滤、操作区、分页和刷新生命周期，卡片仅替换结果展示区域。

## 配置契约

presentation 使用 table/card 判别联合：当前 layout 对应的配置必填，另一模式的配置可选，用于保留已使用模式的设置。卡片实例不强制携带 table，表格实例不强制携带 card；消费者按 layout 收窄后读取当前配置，不通过伪造表格配置满足旧接口。

卡片配置包括：

| 配置    | 规则                                                                                                                                                                            |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| title   | 必选字段引用，允许使用现有字段渲染器及实例级覆盖；原始值缺失时回退记录主键，先判断再格式化                                                                                      |
| cover   | 可选图片地址字段引用；默认 16:9、object-fit: cover，图片替代文本来自标题的纯文本格式化值                                                                                        |
| fields  | 有序摘要字段列表，可为空；每项具有稳定 id、字段路径、可选显示名称及 renderer，默认显示字段名和值                                                                                |
| actions | 类型为 `{ visible?: boolean; renderer?: RendererReference }`；省略 actions 表示未配置，存在时 visible 默认为 true；renderer 省略时继承 definition.recordActions.row，指定时覆盖 |

标题和摘要复用已有字段渲染语义，封面使用图片专用呈现。配置保存为 JSON；不持久化函数、React 节点或运行时渲染器。

操作区启用时必须能解析到有效的渲染器引用：`actions: {}` 且定义没有 recordActions.row 时，配置校验拒绝；指定 renderer 时沿用现有引用校验，name 必填。引用有效但运行时未注册对应组件属于渲染错误，由操作区错误提示处理。

操作区隐藏只设置 `visible: false`，保留 renderer；重新显示设置 `visible: true`，不重新选择渲染器。visible 若提供必须为布尔值，隐藏的已配置引用同样接受结构校验，不用隐藏状态绕过无效配置。此约定复用表格列的 visible 语义，不增加历史配置、恢复缓存或第二套操作注册表。

### 定义级默认配置

ViewDefinition 增加可选 defaultPresentation，作为所有已支持布局共用的默认配置入口。本次包含可选 table 与 card：table 复用实例表格配置类型（columns），card 复用实例卡片配置类型。宿主可通过本地定义或远程 JSON 分别预设各布局；不增加 defaultCard 等布局专属顶层属性。

每个提供的布局预设必须完整有效，不是与实例逐字段合并的补丁；例如 card 省略封面或操作区即表示不显示。defaultPresentation 不设置当前 layout，初始模式仍由实例指定。

所有布局遵循相同优先级：实例已有对应配置 → definition.defaultPresentation 中对应布局预设的深拷贝 → 内置最小配置。提供一个核心初始化函数，供宿主创建实例与引擎首次切换共用。只有缺失的配置才使用默认值，显式传入的无效配置直接报错，不回退或替换。

初始化在选择默认值前校验输入容器及所有已提供的布局配置；仅 undefined 表示缺失，null 必须拒绝，不能被空值合并运算符掩盖。选择后仍校验最终生成配置。初始化单独实现在 resolveRecordPresentation.ts，依赖共用展示校验；校验可依赖 recordPresentation.ts 的纯规则，纯规则不反向依赖初始化或校验，避免循环依赖。

新实例只初始化初始 layout 对应的配置；已有另一模式配置则完整保留。切换时仅补缺失的目标模式配置。表格无预设时，为 definition.fields 每个顶层字段按定义顺序生成一列，以字段路径作为 id，默认全部显示、不启用汇总；嵌套子字段不另行展开，继续使用已有列设置。定义没有可展示字段且无有效 table 配置时，仅创建或切换 table 失败；card 可使用主键标题正常工作。失败不得改变原布局和配置。

持久化加载要求当前布局配置有效；其他模式配置存在时同样校验，但允许缺失。默认值只服务显式创建或切换，不修补损坏的持久化数据。另存为复制当前配置，不重新套预设。

首次切到缺少 card 配置的实例时，初始化和 layout 切换通过一次实例更新完成。加载 table 实例时不提前写入预设，不产生额外 dirty 状态。

初始化后，复制的配置归实例所有，参与保存、另存为和恢复。编辑实例不得修改定义或其他实例；宿主日后更新 defaultPresentation 不覆盖已经保存或编辑过的实例配置。恢复到尚无 card 的保存基线后，下次切换重新使用当前已加载定义的预设。

defaultPresentation 在定义加载时按对应布局的字段、结构及 JSON 规则验证，不符合这些规则的预设报配置错误，不静默改用内置配置。预设不额外加载数据，也不增加新的默认配置服务或全局偏好存储。本次仅统一展示默认配置，不把筛选、排序和分页默认值混入 presentation。

除标题允许引用定义的 rowKey 外，字段引用必须存在于 ViewDefinition.fields；封面字段必须为 string 类型。摘要 id 必须唯一。加载或更新实例时拒绝未知字段、非法配置结构、缺少名称的渲染器引用及不可序列化的 options，不等到查询发出后处理。已有记录主键可能未包含于字段定义时，默认标题直接读取 rowKey，不强制修改宿主定义。

渲染器 options 的业务语义仍由组件在渲染时验证。例如 `{ name: 'text', options: { ellipsis: 'invalid' } }` 通过 JSON 结构校验，但由 TextRenderer 抛错并交给局部错误边界显示。此类语义错误与未注册组件不承诺在查询前发现。沿用现有内置及自定义渲染器机制，不新增选项校验注册系统。

### 未发布版本与契约

5.0.0 尚未发布，本次接受必要的破坏性重构，根目录和各包版本保持 5.0.0。不考虑旧 API 或历史数据迁移，不增加兼容别名、双读双写或过渡模型；源码、示例、测试和文档统一采用最终契约。不执行发布，也不自动删除本地或远程数据。

RecordPresentation 为当前展示的公共联合类型，RecordTablePresentation 和 RecordCardPresentation 分别表达当前布局。表格专属消费者通过类型收窄读取 table，卡片专属消费者读取 card；getRecordSummaryMetrics 接受联合类型，在 card 分支返回空数组，不读取可选 table。
统一使用 resolveRecordPresentation、setCardConfig、RecordCardList、RecordCardFieldConfig。resolveRecordPresentation 是纯配置解析函数：校验、补齐默认值并返回独立配置，不创建实例、不发起查询、不执行持久化。

共享结果工具栏命名为 RecordToolbar（区别于 RecordGlobalToolbar），公开渲染属性为 renderToolbar，上下文为 RecordToolbarRenderContext。工具栏操作注册为 toolbarActions，对应定义字段 recordActions.toolbar 和类型 ToolbarActionsRendererProps，替换现有 tableActions / recordActions.table / TableActionsRendererProps。所有调用者统一更新，不保留别名或旧字段兼容。setColumns 保持表格专属配置编辑语义。

## 切换与设置

顶部全局工具栏统一使用显示当前模式名称的下拉框切换“表格／卡片”，所有宽度采用同一种交互，不维护分段按钮或断点切换逻辑。记录工具栏保留批量操作及列设置/卡片设置。自定义记录工具栏不影响顶部模式切换。

第一次切到卡片时优先复制定义级 defaultPresentation.card，使用户立即看到宿主配置好的卡片。没有预设时生成最小配置：主键作标题，无封面、无摘要，有默认行操作时使用 `actions: {}`，否则省略 actions。设置界面允许选择标题、封面，添加、删除及上下移动摘要字段，选择摘要字段后使用字段默认渲染器。有已配置的操作区或定义级默认行操作时提供显示开关：已有 actions 仅修改 visible；尚无 actions 时可用默认引用创建 `actions: {}`。没有任何可用引用时不提供启用入口。修改其他设置、隐藏操作区、保存和重载均保留显式 renderer，隐藏后仍可重新开启。实例级 renderer 覆盖由配置 API 提供，首版 UI 不编辑任意 JSON 选项。

设置在本地表单草稿中编辑，应用时一次校验和更新，取消不改变实例。切换布局与应用配置标记视图已编辑，沿用保存、另存为、恢复和权限行为。返回表格再切回卡片时，双方配置均保留。

展示方式切换采用“返回时还原该模式上次配置”的语义，不是恢复整份已保存实例。例如 table → card → table 后，表格列顺序、显隐、宽度、固定位置、渲染器和汇总配置必须与离开表格时一致；card → table → card 后，标题、封面、摘要字段顺序、渲染器及操作区显隐也必须与离开卡片时一致。某模式已应用但尚未保存的设置同样保留，不因切换回退到保存基线。只有首次缺少目标模式配置时才初始化，后续切换不重新套预设，不调用 restore()。筛选、排序、分页、游标和选择仍为两种模式共享，切换本身不改变它们；汇总运行结果依照下文生命周期重新计算，不等同于汇总配置丢失。

设置的 onChange 是同步提交契约，绑定实例的 engine.setCardConfig 错误必须向上传递，不通过 RecordView.run 吞掉异常。设置组件捕获错误，在弹层内提示并保留草稿，成功才关闭；页面按钮仍使用原页面错误处理。设置组件不直接依赖引擎，不引入通用提交状态层。

纯展示切换或卡片配置更新不得重新读取记录、改变筛选草稿、排序、页码、游标或当前选择；进行中的查询继续完成。排序仍使用 config.sort 和现有 setSort，切到卡片不增加独立排序状态或新排序面板。

## 渲染与交互

新增 RecordCardList，并由 RecordView 根据 layout 选择结果组件；过滤面板、已应用条件、共享操作区和分页继续共用。卡片使用 CSS Grid 自适应列数，窄屏为单列，继承 fve 主题、字体与语义色。无需固定桌面列数配置。

每张卡片包含可选封面、标题、有序摘要字段及可选操作区。长文本换行，摘要可视觉截断但保留可访问完整内容。整卡默认不绑定点击跳转，以免与选择框、链接、按钮冲突。

RecordView、ViewPageContent、ViewPage 和 RecordCardList 支持可选 renderCard(context)，业务方可完全替换单张卡片的信息结构，或组合 context.defaultContent。上下文包含只读 definition、instance、record、rowKey、index、selected、defaultContent 和绑定实例的 refresh，不暴露引擎或可变状态。列表继续负责网格、选择控件、查询/分页反馈及每卡错误隔离；默认选择控件放在独立区域，不由回调实现。复用 RecordRegion，不增加整卡注册表；回调为本地运行时能力，不写入持久化配置。默认卡片设置只作用于 defaultContent，自定义内容自行决定字段布局。

标题先用现有字段读取函数取原始值：null、undefined 或 trim 后为空的字符串视为缺失，直接以 `String(rowKey)` 呈现兜底标题；0、false 和非空字符串均为有效值。有效值才交给已有格式化及字段渲染流程，不能根据格式化后的 `—` 或自定义 React 节点判断是否缺失。图片替代文本采用同一缺失判断和兜底值；有效标题使用已有格式化函数生成纯文本，不解析自定义渲染器输出。不修改表格及其他字段原有的空值格式化行为。

selectable 开启时提供每卡选择框和本页全选；选中项继续由引擎按 rowKey 管理，批量操作接收同一 selectedRowKeys。使用语义列表和标题结构，控件具有可访问名称、键盘操作和可见焦点。

卡片模式复用现有加载、空结果、失败重试语义，后台刷新保留已有结果。字段或行操作渲染器缺失、抛错仅在对应区域提示，不使整页崩溃。未配置封面时省略图片区域；配置了封面但值缺失、地址不允许或加载失败时显示占位。图片地址仅接受 http/https 和站内相对路径，复用适用的现有 URL 校验；使用浏览器图片加载，不添加服务端抓取。

## 汇总与生命周期

表格汇总配置继续保存在 table.columns，切换时不删除。运行中的汇总指标由现有 getRecordSummaryMetrics 根据当前 layout 提取：table 使用所配置指标，card 返回空数组。沿用 RecordSummaries 的 key、sync、invalidate 和在途请求检查，不增加汇总调度器或布局专属缓存。

切到 card 后调用现有汇总同步流程：取消在途 aggregate，清空汇总运行结果与 key，忽略取消后晚到的响应；进行中的记录查询继续完成。卡片中的加载、筛选、分页、自动刷新及显式 refreshSummary 均不发起 aggregate。getRecordRefreshBlockReason 仅在 table 模式下将汇总 loading 视为暂停原因，UI 和引擎仍共用该判断，避免布局更新与汇总清理之间的短暂状态阻塞卡片刷新。

返回 table 后按当前已应用筛选和保留的列配置同步汇总：用现有记录计算本页指标，需要全量指标时调用 aggregate；没有指标则不查询。返回表格允许重新读取汇总，不重新读取记录，不改变页码、游标或选择。首版每次返回表格重新计算所需汇总，接受这一次明确的读取成本，不引入跨布局缓存有效期策略。

两种布局共用 session、查询取消与刷新策略；不新建卡片 session、QueryApi 或独立数据缓存。

## 实现范围与验证

功能改动集中于 packages/view-engine 的 record 模型、定义及实例校验、引擎编辑入口、RecordView/工具栏及新增卡片和设置组件；按需复用字段呈现内部函数，按最终契约更新公开类型。保持版本 5.0.0，不产生版本升级改动。更新核心和 React 导出、API 参考、README 及对应中英文 wiki，补充含定义级预设的 Storybook 示例。

验收必须覆盖：

1. table/card 当前契约实例均可加载；配置 JSON 保存、加载、另存为和恢复保持一致；非法字段、重复 id、缺少名称的 renderer 引用和不可序列化 options 在加载或更新时被拒绝。
2. 布局来回切换保留双方配置、筛选草稿、排序、分页和选择；paged/cursor 记录查询调用计数不增加，进行中的记录查询不被布局切换取消。另行验证 aggregate：悬挂汇总时切到 card 会取消请求且后台记录刷新可继续；晚到的汇总响应不回写；卡片初始加载、筛选、刷新和 refreshSummary 不查询汇总；返回 table 只补算当前所需汇总，无指标时不查询。
3. table/card 共用默认配置优先级，本地与远程定义行为一致；初始布局分别为 table/card 时，仅要求对应配置有效；首次切换补齐目标配置，已有另一模式配置不被改写。覆盖只有 card 预设、两种预设并存、无预设和已有显式配置的组合；显式无效配置不被预设掩盖。缺失当前布局配置或任何已提供配置损坏时拒绝加载。初始化的深拷贝与定义、其他实例隔离，预设更新不覆盖实例配置；无卡片预设时支持 rowKey 未列入 definition.fields 的既有定义，卡片标题为空时有主键回退。覆盖结构无效预设拒绝、table 加载不产生 dirty、首次切换只更新一次实例以及恢复后重新初始化。
4. 自定义 cells、rowActions 与批量选择正常；验证 actions 省略、空对象继承、显式覆盖以及无默认操作却配置空对象的拒绝路径。没有定义级默认操作时，自定义 actions 经隐藏、应用、保存、重载后仍可重新显示同一 renderer，visible 类型错误被拒绝。内置 renderer 错误选项（如 ellipsis 为字符串）和自定义 renderer 抛错仅影响对应区域，验证它们与加载期结构校验的区别；封面缺失、非法地址和加载失败有稳定回退。
5. 浏览器实际验证切换、设置应用/取消、选择、分页和键盘焦点；检查窄屏、明暗主题、长文本与图片占位。
6. 运行受影响包及依赖构建、包测试与类型检查、相关 Storybook 浏览器测试、文件级格式和 lint；文档更新运行 wiki build。任何提交前 pnpm test:unit 必须通过。
7. 类型消费检查覆盖 RecordPresentation 通用入口、layout 收窄、只有 table 或只有 card 的有效实例，以及 getRecordSummaryMetrics 接受两种布局；所有示例使用最终 API。检查根目录及各包版本仍为 5.0.0。
8. 标题覆盖 null、undefined、空串、纯空白、0、false 和字面量 `—`；只有缺失值回退主键，图片替代文本遵循同一规则。无 table 预设时所有顶层字段均进入列配置，列 id 稳定且唯一，列设置可隐藏及重新显示各字段；有预设时严格保留预设列，不自动补列。
9. 默认初始化对显式 null、非法容器及未启用布局的非法配置均拒绝，对 undefined 缺失正常回退；检查初始化与校验模块没有反向循环依赖。设置提交失败时弹层、草稿保留，成功重试才关闭，取消或切换实例丢弃旧草稿。

## 规格自审

- 两种布局彼此独立，已存在的配置在往返切换时保留。
- 展示更新与记录查询分离；卡片无运行汇总，返回表格允许按当前条件重算汇总。
- 默认主键标题不假定 rowKey 必须出现在可选字段列表中。
- table/card 使用同一个默认配置入口与初始化规则；实例配置优先且不逐字段合并，预设更新不覆盖用户编辑，也不放宽持久化实例校验。
- 新实例只初始化目标布局，已保存实例缺少当前布局配置时才报错。
- 本次属于未发布的 5.0.0，统一最终契约，不增加迁移或兼容机制。
- 操作区复用 visible 语义，隐藏保留 renderer；无默认引用时拒绝空对象。
- 加载期负责字段、结构和 JSON 校验；渲染器选项语义及组件注册问题由局部渲染错误处理。
- 区分可配置的 renderer API 与首版设置 UI，未承诺 JSON 渲染器编辑器。
- 标题先判原始值再格式化；无表格预设时生成全部顶层字段列，复用既有列设置。
- 本地验证记录见实施计划；不代表宿主生产服务或发布验收。
- 初始化与校验单向依赖；先验证显式输入再选择默认值；设置错误由设置组件显示并保留草稿。

## 产品体验修订

添加摘要候选耗尽时禁用控件并显示“已添加全部字段”；封面关闭状态明确显示“无封面”。设置提示仅说明“应用到当前视图”，不承诺宿主未提供的保存能力。Storybook 另提供 LocalStorageViewHost 的完整保存示例和自定义卡片示例。

主卡片示例采用订单工作台，默认卡片和自定义卡片均包含查看详情、处理订单；共享工具栏提供批量处理，全局工具栏提供创建订单。复用已有订单服务和 OrderOperationsProvider，实际修改本地示例记录并刷新当前筛选队列；处理后不再符合待办条件的记录退出当前列表。失败重试沿用“写入成功后只重试刷新”的现有规则，不增加第二套卡片操作机制。示例明确说明记录仅保留当前页面，视图配置可选 localStorage 保存。

### 已确认：展示能力与紧凑工具栏

- `ViewDefinition.allowedLayouts` 必填，非空且不重复；允许 table、card 或两者。共享展示验证拒绝未允许的活动布局，覆盖实例加载和引擎编辑；只有一种时不渲染切换入口。
- 模式切换保持双方已有配置；未发布的 5.0.0 直接采用新契约，不提供迁移。
- 卡片选择为右上角按钮，使用 `aria-pressed` 与选中边框，不占独立行；整卡点击不触发选择。自定义内容需避让角标。
- 顶部模式、筛选与演示创建操作图标化，保留可访问名称和提示。下拉选项及视图名称保留文字。
