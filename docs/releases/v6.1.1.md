# fetcher v6.1.1 release notes

A maintenance release of the 6.x line. Its one change since v6.1.0 marks the
CoSec integration deprecated: it moved to the CoSec repository (#2083).
Nothing behaves differently.

## Deprecated

- **`@ahoo-wang/fetcher-cosec`** moved to
  [`@ahoo-wang/cosec-fetcher`](https://www.npmjs.com/package/@ahoo-wang/cosec-fetcher).
  Every export carries a JSDoc `@deprecated` tag, and the README and the
  `package.json` description say where the package went.
- **The CoSec hooks of `@ahoo-wang/fetcher-react`** — `SecurityProvider`,
  `SecurityContext`, `useSecurity`, `useSecurityContext`, `RouteGuard`,
  `RefreshableRouteGuard`, `ANONYMOUS_USER` and their types — moved to
  [`@ahoo-wang/cosec-react`](https://www.npmjs.com/package/@ahoo-wang/cosec-react).
  They carry the same `@deprecated` tag, and the README says so.

The deprecation is documentation only: JSDoc tags, which editors and
TypeScript show as a strikethrough, the READMEs and the `package.json`
description. There is no runtime warning, and 6.x behaves as in v6.1.0.

The replacement packages are `8.0.0-beta.3` today and are published only under
npm's `beta` tag; their stable release comes with CoSec 8.0 GA. Until then,
install them with `@beta` (`pnpm add @ahoo-wang/cosec-fetcher@beta`): their
`latest` tag holds a `0.0.0` placeholder. Migration and documentation:
[https://cosec.ahoo.me/integration/clients](https://cosec.ahoo.me/integration/clients).

`@ahoo-wang/fetcher-cosec` and the CoSec hooks are removed in the next fetcher
major, along with `@ahoo-wang/fetcher-react`'s peer dependency on
`@ahoo-wang/fetcher-cosec`. The 6.x line keeps them and stays usable.

## Maintenance

- The CI, Engineering Quality, Storybook, integration and PR metadata
  workflows run for the `6.x` maintenance branch, so its pull requests are
  checked and its release commits can pass release admission (#2083).
