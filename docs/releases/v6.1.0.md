# fetcher v6.1.0 release notes

## Highlights

- **Problem details (RFC 9457)** (#2075). A response rejected by status
  validation that is `application/problem+json` now carries its parsed problem
  details on `HttpStatusValidationError.problem`, read from a copy of the body.
- **63 defects fixed** across every package, from a review of 6.0.1. Most are
  edge cases: objects from another realm (a same-origin iframe, a Node `vm`
  context), the ES module and CommonJS builds loaded together, cancellation
  and retry races, and declarations that did not match the runtime.
- **ES module and CommonJS declarations accept each other's instances**
  (#2070, #2074). A `Fetcher`, `TokenStorage` or `KeyStorage` made through one
  entry is assignable where the other entry's type is expected.
  `check:package-types` now checks this for every package.

## Upgrade notes

These are the changes that may need a change on your side.

- **`@ahoo-wang/fetcher-cosec` requires Node `^22.12.0 || ^24.0.0 || >=26.0.0`**
  (#2069, #1986). Its dependency nanoid 6 is ES modules only and supports
  Node 22, 24 and 26+; CoSec's CommonJS entry loads it with `require()`, which
  works from Node 22.12. Node 20 is no longer supported by CoSec (it reached
  end of life in April 2026). The other packages still declare `>=18.20.8`.
- **`@ahoo-wang/fetcher-openapi`: `Paths`, `Responses` and `Callback` are keyed
  by `PathKey`, `HttpStatusCodeKey` and `CallbackExpression`** (#2073, #2034),
  so their `x-*` extension members type-check. Reading one of these maps with
  a plain `string` key no longer compiles under `noImplicitAny`; type the key
  (`responses[status as HttpStatusCodeKey]`) or iterate with `Object.entries`.
- **`@ahoo-wang/fetcher-openai`: `ChatClient` takes `ChatClientOptions`**
  (#2073, #2052), which leaves out `resultExtractor` and `returnType`: the
  client decides its result shape. A value typed as plain `ApiMetadata` no
  longer compiles there. `Message.content`, `Choice.finish_reason` and
  `ChatResponse.usage` may be `null` (#2043).
- **Formerly private members are public and marked `@internal`** (#2070,
  #2074). Runtime behavior is unchanged. A subclass that overrides
  `handleEvent`, `ownEventBus`, `enqueue` or `terminate` and declares it
  `protected` must drop `protected`. `SafeTransformer`'s `onTransform`,
  `onFlush` and `onError` hooks stay protected.
- **`@ahoo-wang/fetcher-storage` broadcasts carry an ordering stamp**
  (`__fetcher_storage_stamp__`, #2072), so caches ignore out-of-order changes.
  Older versions in other tabs ignore the field.
- **The built-in body extractors are typed by their body** (#2039):
  `TextResultExtractor` is a `ResultExtractor<string>`, not a
  `ResultExtractor<Promise<string>>`.

## Added

- `@ahoo-wang/fetcher`: `ProblemDetails`, `isProblemDetailsResponse`,
  `readProblemDetails`, `toProblemDetails`, `ABOUT_BLANK_PROBLEM_TYPE`,
  `ContentTypeValues.APPLICATION_PROBLEM_JSON`, `ValidateStatusOptions`,
  `FetcherOptions.problemDetails` (default `true`), and
  `HttpStatusValidationError.problem` (#2075).
- `@ahoo-wang/fetcher`: `copyQuery` and `mergeQuery`, which keep a
  `URLSearchParams` query with its repeated keys (#2055).
- `@ahoo-wang/fetcher-openapi`: `PathKey`, `HttpStatusCodeKey`,
  `CallbackExpression` (#2073).
- `@ahoo-wang/fetcher-openai`: `ChatClientOptions` (#2073).

## Fixed

**`@ahoo-wang/fetcher`**

- Values from another realm are recognized: a `Date` is formatted as ISO 8601
  with milliseconds, a `Map` of attributes keeps its entries, and a `File`,
  `Blob`, `FormData`, `URLSearchParams`, `ArrayBuffer` or `ReadableStream` body
  is sent as is instead of as `{}` JSON (#2003, #2028, #2046).
- A `URLSearchParams` query is no longer dropped (#1988); a rejection with
  `undefined` or `null` no longer counts as a recovery (#2016); a path
  parameter named like an `Object.prototype` member counts as missing
  (#2025); an empty `Content-Type` the caller set is kept (#2050).
- Without `AbortSignal.any`, the caller's signal still cancels the body after
  the headers (#1989); a timeout rejects with `FetchTimeoutError` even when the
  fetch rejects synchronously on abort (#2013).
- Trust is judged by the host a relative URL resolves to, and a relative
  `baseURL` is not applied twice when the request chain runs again (#1995,
  #2009).

**`@ahoo-wang/fetcher-decorator`**

- Parameter names are read from the signature by ECMAScript rules: unparenthesized
  arrow parameters, default values with commas or parentheses, and Unicode
  names (#2015, #2031, #2051).
- Arguments from another realm (plain objects, `AbortSignal`,
  `AbortController`) bind as from this realm; `__proto__` keys are kept
  (#2024, #2032, #2037); header removals survive merging (#2002).
- Endpoints bind to the nearest implementation in deep hierarchies,
  metadata is shared between the ES module and CommonJS builds, and `@api`
  accepts abstract and private-constructor classes (#1990, #2022, #2047).

**`@ahoo-wang/fetcher-cosec`**

- Default storages stay private outside the browser's `localStorage`, so
  Node SSR requests never share credentials through `BroadcastChannel`; a
  malformed token record is rejected (#1999, #2001).
- 401 recovery: only trusted origins trigger a refresh, the retry keeps the
  original space, request body and response release, and a failed retry
  after a successful refresh does not sign the user out (#1996, #1997,
  #1998, #2020, #2033).
- A refresh is committed against the stored state, handles synchronous throws
  and refreshers from another module copy, and notifies once (#2000, #2019,
  #2027); `tenantId`/`ownerId` placeholders in the Fetcher `baseURL` are filled
  (#2038); the declared Node range matches nanoid (#2012).

**`@ahoo-wang/fetcher-react`**

- Leading debounce ends on quiet time and effect cleanup, StrictMode replays
  keep leading-only requests, and function values are not run as
  initializers (#1991, #1992, #2011).
- An execution has its identity from the moment `execute` is called:
  re-entrant `onAbort`, caller-signal aborts and resumed Activity calls no
  longer cross (#2006, #2018, #2023).
- `useEventSubscription` removes only its own subscription (#1993, #2048);
  a pending `signIn` is superseded and `RefreshableRouteGuard` refreshes each
  session (#2004, #2005).
- Stored values are returned by reference, nullable defaults and Immer drafts
  are typed (#2010, #2035, #2036); colliding API hook names are reported,
  a foreign `Object.prototype` is skipped and primitive queries are sent as
  JSON (#2017, #2040, #2045).

**`@ahoo-wang/fetcher-storage` and `@ahoo-wang/fetcher-eventbus`**

- Cache updates are ordered, so a parallel bus or a delayed broadcast no
  longer leaves an older value (#1994, #2029); internal listeners of the ES
  module and CommonJS copies no longer collide (#2007); an old remover no
  longer deletes a re-registration (#2049); `reload()` keeps the cached object
  when the stored value is unchanged (#2041); destroying a bus twice is
  harmless (#2021).

**`@ahoo-wang/fetcher-eventstream`, `@ahoo-wang/fetcher-openai`, `@ahoo-wang/fetcher-openapi`**

- The SSE extractors accept a `Response` from another constructor (#2030);
  the async-iteration fallback honors `preventCancel` (#2044); chat types allow
  `null` where the API sends it (#2043); `ChatClient` metadata cannot change
  the result shape (#2052); OpenAPI maps accept `x-*` extensions (#2034).

**Tooling**

- `pnpm init` stops at the first failed step (#2014); the Storybook browser
  acceptance script targets the current stories (#2008); the wiki Mermaid
  fixer changes nothing when the Mermaid CLI cannot run (#2026).
