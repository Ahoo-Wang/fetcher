# Declarative services — `@ahoo-wang/fetcher-decorator`

A class decorated with `@api(basePath, metadata?)` gets its endpoint methods
implemented at run time. The method body is a placeholder:
`throw autoGeneratedError(...args)` (the arguments only silence unused-parameter
lint).

## Setup that is easy to miss

- **Legacy decorators**: the app's tsconfig needs `experimentalDecorators: true`;
  with standard (TC39) decorators decoration throws a `TypeError`.
  `emitDecoratorMetadata` is not needed.
- **Name the fetcher**: `@api('/users', { fetcher: 'api' })`. Without it the
  service uses the `'default'` fetcher (`baseURL: ''`), so requests go to the
  page origin with none of your interceptors. A name that is not registered
  throws a plain `Error` at call time; import the module that constructs the
  `NamedFetcher` first. Precedence: endpoint metadata, then the instance's
  `apiMetadata`, then `@api`.
- **Call methods on the instance.** A detached method (`const f = service.get`)
  throws a `TypeError`.

## Endpoints

`@get`, `@post`, `@put`, `@patch`, `@head`, `@options`, and **`@del`** for
DELETE (there is no `@delete`). Anything else: `@endpoint(HttpMethod.TRACE, path)`.
The second argument takes `resultExtractor`, `returnType`, `timeout`,
`headers`, `attributes`, `fetcher` and `urlParams`.

**Decorated methods resolve to parsed JSON by default**, unlike plain
`fetcher.get`. Consequences:

- A `204` or empty body rejects with a raw `SyntaxError` (not an
  `ExchangeError`, unseen by interceptors). For no-content endpoints use
  `resultExtractor: ResultExtractors.Response`, or
  `returnType: EndpointReturnType.EXCHANGE` to get the `FetchExchange`
  (headers, status). `EXCHANGE` still rejects on non-2xx.
- Streams: `resultExtractor: jsonEventStreamResultExtractor<T>(detector)` from
  `@ahoo-wang/fetcher-eventstream`.

## Parameters

- `@path('id')`, `@query('page')`, `@header('X-Id')`, `@body()`,
  `@attribute('key')`, `@request()` (a partial request merged in).
- **Always pass the name.** An unnamed decorator reads the parameter name from
  the compiled function source; a minifier renames it and the value is sent
  under the mangled name (only `@path` warns, once).
- **An undecorated parameter is ignored** — a forgotten `@body()` drops the
  body silently. The one exception: any `AbortSignal` or `AbortController`
  argument cancels the request, whatever its decorator.
- **Binding by shape**: a plain object passed to `@path()`, `@query()` or
  `@header()` (unnamed) is spread into its keys (`null` entries dropped); an
  array, `Date` or class instance is bound to the parameter's name
  (`@query('ids') ids: number[]` → `ids=1&ids=2`; a header array is joined with
  `, `). `null`/`undefined` arguments are skipped. A named `@attribute('user')`
  stores the object whole.

## `ExecuteLifeCycle`

Implement `beforeExecute(exchange)` / `afterExecute(exchange)` on the class.

- `beforeExecute` runs before every interceptor: the URL is still the template.
- **`afterExecute` is skipped whenever the chain throws** — a 401, any non-2xx,
  a network error. It is not a `finally` and cannot react to auth failures; use
  an error interceptor on the fetcher (or CoSec's `onUnauthorized`).

## Inheritance and per-instance config

- `@api` binds endpoint methods along the prototype chain using the subclass's
  base path and fetcher. An override without its own endpoint decorator runs as
  written.
- `apiMetadata` on an instance (`{ fetcher, headers, timeout, … }`) applies on
  the next call, whether replaced or changed in place.

## Example

```ts
import { ResultExtractors } from '@ahoo-wang/fetcher';
import {
  api,
  autoGeneratedError,
  body,
  del,
  get,
  path,
  post,
  query,
  type ExecuteLifeCycle,
} from '@ahoo-wang/fetcher-decorator';
import type { FetchExchange } from '@ahoo-wang/fetcher';
import './api'; // constructs new NamedFetcher('api', …)

@api('/users', { fetcher: 'api' })
export class UserService implements ExecuteLifeCycle {
  @get('/{id}')
  getUser(@path('id') id: number): Promise<User> {
    throw autoGeneratedError(id);
  }

  @get('')
  list(
    @query('page') page?: number,
    @query('ids') ids?: number[],
  ): Promise<User[]> {
    throw autoGeneratedError(page, ids);
  }

  @post('')
  create(@body() user: Omit<User, 'id'>): Promise<User> {
    throw autoGeneratedError(user);
  }

  @del('/{id}', { resultExtractor: ResultExtractors.Response })
  remove(@path('id') id: number, signal?: AbortSignal): Promise<Response> {
    throw autoGeneratedError(id, signal);
  }

  beforeExecute(exchange: FetchExchange) {
    console.debug('→', exchange.request.url);
  }
}

export const userService = new UserService();
```
