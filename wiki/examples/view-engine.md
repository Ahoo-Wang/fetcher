# Complete View Engine example

The shared runnable example is being rebuilt together with the package. It returns when the Record workbench ships, which is the first user-visible step of the [rewrite](https://github.com/Ahoo-Wang/fetcher/blob/main/packages/view-engine/docs/design.md): filter pending orders, adjust columns and sorting, save a personal view, reopen it.

Until then, the target usage is shown in the package [README](https://github.com/Ahoo-Wang/fetcher/blob/main/packages/view-engine/README.md), and the previous example is available at the git tag `view-engine-legacy`.
