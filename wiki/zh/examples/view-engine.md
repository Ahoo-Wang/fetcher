# 完整 View Engine 示例

共享的可运行示例正与包一起重建。它将随 Record 工作台一起回归，那是[重写](https://github.com/Ahoo-Wang/fetcher/blob/main/packages/view-engine/docs/design.md)第一个用户可见的步骤：筛选待出库订单、调整列与排序、保存为个人视图、重新打开。

在此之前，目标用法见包内 [README](https://github.com/Ahoo-Wang/fetcher/blob/main/packages/view-engine/README.zh-CN.md)，旧示例见 git tag `view-engine-legacy`。
