# 运行完整示例

每个示例包含维护中的源码、前提、运行命令、预期结果和清理方式。仓库夹具不需要外部后端。

| 示例                            | 运行后观察                                      | 接入应用                                           |
| ------------------------------- | ----------------------------------------------- | -------------------------------------------------- |
| [HTTP](./http.md)               | 本地服务返回 Ada；不存在的路由产生 HTTP 404     | 将服务与客户端复制到独立 ESM 项目                  |
| [React](./react.md)             | 加载、失败、启动延迟请求并取消                  | 在已有 React 应用挂载组件，并提供文档列出的路由    |
| [Viewer](./viewer.md)           | 四行数据、分页、姓名排序、Active 过滤与保存确认 | 在兼容的 React/Viewer peer 环境挂载本地组件        |
| [View Engine](./view-engine.md) | 三笔订单，通过 ViewPage 手动查询、排序和分页    | 在 React 19 应用中使用当前工作区或验证后的本地归档 |

Viewer 示例将视图保存在组件内存，重新挂载会重置。React 夹具的慢请求耗时 2000 ms，便于观察取消。这些检查证明示例行为，不证明认证、服务端一致性或生产持久化。

完成一个基线后，选择[开发任务](../guides/index.md)，或查看[资源归属](../architecture/state-and-resources.md)。
