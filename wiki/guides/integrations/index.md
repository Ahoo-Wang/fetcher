# Platform integrations

Wow requires compatible server protocols and application-specific routes. Storage and local events can be used without a platform server. Confirm the chosen package peers before installing.

- [Send commands and query state](./wow.md) (5.x only; from 6.0 see [wow.ahoo.me](https://wow.ahoo.me))
- [Share storage and events](./storage-and-events.md)

CoSec authentication moved to the CoSec repository: use `@ahoo-wang/cosec-fetcher` (was `@ahoo-wang/fetcher-cosec`) and `@ahoo-wang/cosec-react` (was the security hooks in `@ahoo-wang/fetcher-react`), on npm's `beta` tag until CoSec 8.0 GA. See [cosec.ahoo.me](https://cosec.ahoo.me/integration/clients).
